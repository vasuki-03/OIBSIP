# Unemployment Analysis with Python

## Internship
OASIS INFOBYTE — Data Science Internship

## Objective
To analyse unemployment trends in India, compare regional unemployment rates, and explore relationships between unemployment, employment and labour-force participation.

## Dataset
The project uses the following Kaggle datasets:

- [Unemployment in India](https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india)

The downloaded archive contains two CSV files: `Unemployment in India.csv` and `Unemployment_Rate_upto_11_2020.csv`.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Load and inspect the datasets.
2. Clean missing values and duplicate records.
3. Analyse unemployment-rate distributions.
4. Compare monthly unemployment trends across three regions.
5. Identify regions with high average unemployment rates.
6. Examine employment and labour-force participation.
7. Compare unemployment averages before and from March 2020 onwards.
8. Visualise correlations between employment indicators.

## Key Observations
- The unemployment-rate distribution is right-skewed, with some unusually high observations.
- Unemployment trends vary across the three selected regions.
- The average unemployment rate was 9.51% before March 2020 and 17.77% from March 2020 onwards in the analysed dataset.
- The correlation between unemployment rate and estimated employment was approximately -0.22.

These observations describe the available dataset and do not establish causation.

## Conclusion
This project demonstrates how Python libraries can be used to clean, analyse and visualise unemployment-related data. The visualisations help explore regional differences, changes over time and relationships between employment indicators.
