# Task 3: Car Price Prediction with Machine Learning

## Objective
To build regression models that predict the selling price of used cars based on their features.

## Dataset
Vehicle dataset from CarDekho, containing car details such as manufacturing year, selling price, present price, kilometres driven, fuel type, seller type, transmission and ownership.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
1. Data loading and cleaning
2. Feature engineering: car age and brand extraction
3. Exploratory data analysis and visualisation
4. Feature correlation heatmap
5. Categorical encoding and train-test split
6. Linear Regression and Random Forest model training
7. Model evaluation using MAE, RMSE and R² score
8. Feature importance analysis
9. Sample car selling-price prediction
10. Final validation

## Model Evaluation
The models are compared using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE) and R² score. The actual evaluation results are available in the Jupyter Notebook.

## Conclusion
This project demonstrates how regression models can be used to estimate used car selling prices from vehicle features.
